大模型应用开发入门指南

一、什么是大模型应用开发？
大模型应用开发是指基于已有的大语言模型（如 GPT、Qwen 等），通过 API 调用、Prompt 工程、RAG、Agent 等技术，构建面向用户的 AI 应用。与训练模型不同，应用开发的重点是「如何用好模型」，而不是「如何训练模型」。

二、RAG 是什么？
RAG（Retrieval-Augmented Generation，检索增强生成）是一种让大模型「先查资料再回答」的技术。基本流程：
1. 文档切分：把长文档切成小段（chunk）
2. 向量化：用 Embedding 模型把每段文字转成向量
3. 存储：向量存入向量数据库（如 Chroma）
4. 检索：用户提问时，找出最相关的文档片段
5. 生成：把检索到的片段作为上下文，让大模型生成答案

三、常用技术栈
- 前端界面：Streamlit、Gradio
- 大模型 API：OpenAI、阿里云百炼、DeepSeek
- 框架：LangChain、LlamaIndex
- 向量库：Chroma、FAISS、Milvus
- 文档解析：PyPDF、Unstructured

四、学习建议
1. 先跑通 API 调用，再学 RAG
2. 每个 Demo 都要能演示、能讲清楚原理
3. 项目放 GitHub，简历写清楚技术栈和成果
